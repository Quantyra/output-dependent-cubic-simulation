This completes the formalization side of the sign clause. The chain now reads: the support sign is the recorded constant xored with the parity of products of canonical paired coordinates; the canonical coordinate map is linear, so a support point shifted by a computed kernel element has canonical coordinates equal to the base point's xored with the kernel element's; and the kernel element's canonical coordinates are exactly the paired-block assignment that produced it, at the even and odd positions of each pair.
